# Number-Guessing-Game

A console-based **Number Guessing Game** built to test and consolidate my **C programming** skills acquired in the **CSE-1201** course. This hands-on project bridges classroom learning with real application.

---

## Project Description

An interactive **C-based** terminal application that adds a competitive twist to the classic **number-guessing** challenge. Players attempt to uncover a hidden secret number between **1 and 100** while receiving instant **"Higher"** or **"Lower"** feedback after each guess.

---

## Features

- Dual Game Modes
- Real-time Hints
- **Smart Timer & Tiebreaker** System
- Custom **Player Profiles**
- **Vibrant ANSI Color** UI

## Game Rules

- Computer will pick a secret random number between 1 and 100.
- Try to guess it in as few attempts as possible!
- You will get hints like 'Higher' or 'Lower' after each guess.
- In Group Mode, whoever guesses in fewer tries wins!
- In case of a tie in guess count, time is the tiebreaker.
